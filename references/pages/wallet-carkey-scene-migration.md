# 迁移车钥匙

_Source: https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/wallet-carkey-scene-migration_

用户更换移动设备后，车钥匙自动迁移至新设备，无须重新线下配对，保障用户持续使用数字车钥匙的便捷体验。

交互流程

服务端开发

在开通车钥匙的服务器激活过程中，DK服务器收到钱包App（经过钱包服务器代理）的设备认证请求时，需要留存请求中的华为账号OpenId，建立双端账号对应关系，用作后续用户将车钥匙从老设备迁移到新设备。

收到新设备上钱包App（经过钱包服务器代理）的迁移车钥匙请求之后，DK服务器向钱包服务器申请ICCE钥匙。

申请成功之后，将生成的车钥匙JWE数据作为迁移车钥匙请求的响应返回钱包App。

钱包App与DK服务器进行激活车钥匙的服务器交互，激活车钥匙过程参见开通车钥匙服务端开发步骤3。

车钥匙激活成功之后，DK服务器收到新设备车钥匙开通成功的NFC相关事件回调通知接口之后，触发老设备删除车钥匙。
