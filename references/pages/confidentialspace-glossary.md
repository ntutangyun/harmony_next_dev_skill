# Confidential Space Kit术语

_Source: https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/confidentialspace-glossary_

C

[h2]Confidential Space；机密空间

一种对外隔离的计算环境，可运行独立程序并使用外部引入的数据，但从空间向外发送的数据量被严格管控。用于防止隐私信息外泄，专注于用户隐私数据的计算。

D

[h2]Data Application (DA)；数据应用

运行于机密空间内部的独立程序，可使用外部应用提供的数据及机密空间内部开放的系统数据，完成特定计算任务后将最终结果发送回外部应用。
