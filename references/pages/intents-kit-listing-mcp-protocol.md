# MCP协议上架指导

_Source: https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/intents-kit-listing-mcp-protocol_

MCP注册配置操作步骤

进入MCP配置操作入口。

登录华为开发者联盟 ，选择“管理中心 > 生态服务 > 智慧服务 > 小艺开放平台”，在管理中心找到小艺开放平台。

点击“立即体验”按钮，进入项目管理页面。

在资源库中点击“MCP”页签，即可到达MCP配置操作入口。

新建MCP。

在资源库的“MCP”页签下，点击“新建MCP”按钮，创建一条MCP记录。

选择“标准注册方式”并填写基本信息，创建MCP。

MCP名称：需唯一标识。

MCP描述：开发者自定义插件描述信息。

分类：按业务场景选择。

MCP服务配置：填写MCP URL（服务器地址信息，不含鉴权信息）。

认证信息配置：MCP的鉴权信息（选择Header/Query其中一种认证方式进行填写）。

协议类型：开发者根据自身MCP的实现方式进行选择。

选择“外部平台导入”方式创建MCP的步骤，可参考外部平台导入章节。

创建MCP后，切换至“插件信息”页签，编辑并保存MCP插件的基本信息。

编辑基本信息：

开发者品牌：该信息是对外露出的品牌传播名（注意和企业账号，公司名称区别开）。

图标：尺寸要求为192px*192px；格式要求文件类型为png、jpg、jpeg任意一种；样式要求图标为方角图标且背景色不透明。

工具检查：保存基本信息后，切换至"工具"页签。若基本信息配置无误，工具列表中会自动拉取出开发者该MCP下的所有工具信息。

出现工具列表：请点击“配置”，检查工具入参，参数是否重复或者缺失，参数类型是否正确。若一切无误，则配置成功。

未出现工具列表：请等候几分钟重新进入，后台加载存在延时；如若重新进入后，仍未加载出工具信息，可能是插件的链接和鉴权信息配置错误。如果以上方法仍未解决您的问题，可以通过在线工单系统与我们进行联系，提交后的工单可在开发者联盟“管理中心”的“开发者中心 > 我的客服”页面查看工单处理进展。

审核：切换至“发布”页签，点击“提交审核”。

选择发布渠道，点击确定，提交审核。

智能体：开发者上架MCP Server，仅供开发者自己开发的智能体来调用。发布后即可上架成功，无需人工审核。

小艺对话：开发者上架MCP Server，可供开发者自己开发的智能体调用，也可供小艺App主对话调用，发布后必须经过意图框架人工审核。请根据Intents Kit接入流程，提交意图框架的技能调用方案能力申请，明确此次MCP发布的相关需求背景和审核诉求。

插件市场：开发者上架MCP server，可供开发者自己开发的智能体调用，也可供插件市场上其他的开发者发现和使用，发布后必须经过意图框架人工审核。请根据Intents Kit接入流程，提交意图框架的技能调用方案能力申请，明确此次MCP发布的相关需求背景和审核诉求。

提交审核后，请耐心等待平台相关审核流程完成；审核完成后可在小艺开放平台内的插件市场里找到您的工具。
