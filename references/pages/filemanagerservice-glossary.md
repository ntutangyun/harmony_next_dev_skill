# File Manager Service Kit术语

_Source: https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/filemanagerservice-glossary_

F

[h2]File icon；文件图标

与文件类型关联的图形标识，用于在文件管理等应用界面中展示文件类型对应的图标。

R

[h2]Recycle bin；回收站

用户删除公共目录文件的临时存储区域，删除的公共目录文件会被移入回收站而非直接永久删除。

S

[h2]Shortcut file；快捷方式文件

指向原文件的链接文件，后缀为".hlink"，通过解析快捷方式文件可获取其指向的原文件URI，常用于通过快捷方式打开原文件的场景。
